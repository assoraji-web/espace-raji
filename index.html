Espace RAJI

Ajoutez l’icône RAJI sur l’écran d’accueil de votre téléphone : un seul geste pour ouvrir votre espace.

Ouvrir l’Espace RAJI

📱 Android (Chrome)

  1. Touchez les trois points ⋮ en haut à droite de Chrome.
  2. Choisissez « Installer l’application » ou « Ajouter à l’écran d’accueil ».
  3. Confirmez. L’icône RAJI apparaît parmi vos applications.

🍎 iPhone (Safari)

  1. Ouvrez cette page dans Safari (pas dans WhatsApp ni Facebook).
  2. Touchez le bouton Partager (carré avec une flèche vers le haut).
  3. Faites défiler et touchez « Sur l’écran d’accueil », puis « Ajouter ».

À savoir

• Votre code personnel est toujours demandé la première fois ; cochez « Mémoriser cet appareil » sur votre téléphone personnel pour ne plus le ressaisir.

• Ne partagez jamais votre code. Cette page ne contient aucune donnée de l’association.

• Si l’icône ouvre une page vide, ouvrez d’abord le lien reçu par e-mail puis réessayez.
